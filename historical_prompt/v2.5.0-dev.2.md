### 3.4 Catalogue directory — percentage precision

**New requirement**

Inside More → Workbook comments → Catalogue → Table, percentage values are not rounded to two decimal places.

#### Required behavior

Display percentage values with a maximum of two decimal places.

Examples:

| Underlying percentage | Display |
|---:|---:|
| 0.123456 as a percentage | 12.35% |
| 0.5 as a percentage | 50% or 50.00%, following the established display convention |
| 1.0 as a percentage | 100% or 100.00%, following the established display convention |
| 0.00004 as a percentage | 0% or 0.00%, following the established display convention |

The key requirement is that the displayed percentage must not exceed two decimal places.

Inspect the existing UI's number-formatting conventions and apply a consistent presentation.

#### Important precision rules

- Do not alter the underlying numeric value.
- Do not round data before storing it.
- Do not introduce repeated percentage scaling.
- Do not multiply an already percentage-scaled value by 100 again.
- Do not apply percentage formatting to ordinary numeric values.
- Respect Excel number-format metadata where available.
- Preserve the distinction between raw numeric values and formatted display strings.

For example, if the raw value is `0.123456` and the cell is formatted as a percentage, the displayed value should be `12.35%`.

If the source value is an ordinary decimal and the cell is not percentage-formatted, do not automatically append `%`.

#### Tests

Cover:
- Positive percentages.
- Negative percentages.
- Zero.
- Very small percentages.
- Values requiring rounding up.
- Values requiring rounding down.
- Already formatted percentage cells.
- Ordinary decimal cells.
- Integer values.
- Missing values.

Verify that percentage formatting is limited to the Catalogue Table display layer unless the existing shared formatter is demonstrably the correct reusable location.
