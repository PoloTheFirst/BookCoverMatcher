- Text search over meaningful available record fields.
- Date-range filtering.
- Clear/reset action.
- Active-filter indication.
- Empty state when no records match.

- Work independently in Published and Acquired modes.
- Operate on actual records.
- Preserve chronological ordering.
- Not modify source workbooks.
- Handle unknown, invalid, and ambiguous dates explicitly.
- Not silently discard records due to missing optional metadata.
- Avoid overcrowding the UI.

### 4.3 Gallery: improve search/filter spacing

Improve the visual separation between the Gallery search bar and these existing filters:

- All
- With cover
- No cover
- Missing title
- Missing metadata

Requirements:

- Make the search bar visually distinct from the filter controls.
- Use appropriate spacing, grouping, padding, or a subtle divider.
- Do not shrink font sizes to solve the problem.
- Preserve existing search and filter functionality.
- Avoid excessive vertical space.
- Preserve the previously implemented Gallery scroll-reset behavior when the displayed item order actually changes.

### 4.4 Insights directory: fix title and count layout

Redesign the directory heading into two lines:

- First line: directory title.
- Second line: directory count, positioned toward the bottom of the heading area.

Example:

    Insights
    [Directory count]

The title and count must remain visible when a spreadsheet is opened, during loading, after navigation, and following data updates.

Investigate and fix the underlying issue. Check conditional rendering, loading branches, state-holder lifecycle, parent layout replacement, and data-source lifecycle.

Preserve the existing meaning of the count. Do not silently redefine what is counted.

### 4.5 Health and Analytics: add worksheet selection

Add worksheet filters to both Health and Analytics.

Users must be able to select:

- All worksheets.
- One worksheet.
- Multiple worksheets.

Requirements:

- Default to all worksheets unless the existing persisted preference says otherwise.
- Show selected worksheet names or a clear selection summary.
- Support workbooks with many worksheets.
- Handle removed, renamed, and stale worksheet selections safely.
- Scope selections appropriately to the active workbook.
- Show an appropriate empty state if no eligible worksheets exist.
- Do not hardcode sample workbook worksheet names.

**Health:** All findings and summary counts must be calculated from the selected worksheets only.

**Analytics:** All summary metrics, charts, distributions, and date analysis must be calculated from the selected worksheets only.

Do not merely hide results in the UI after calculating from all worksheets.

Use a reusable selection component/model where appropriate, but keep Health and Analytics selections independent unless the existing architecture explicitly establishes a shared preference.

Use stable worksheet identifiers where available.

### 4.6 Insights directory: change function order

The displayed order must be exactly:

1. Health
2. Analytics
3. Gallery
4. Timeline

This groups:

- Health + Analytics: data analysis and findings.
- Gallery + Timeline: browsing and exploring records.

Preserve all navigation destinations, implementations, and state ownership.

Verify every entry opens its correct screen.
