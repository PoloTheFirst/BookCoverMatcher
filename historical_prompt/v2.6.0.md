## 3. Feature 1 — Markdown reader for open-source licences

### 3.1 Current-state investigation

Inspect how the application currently presents open-source licence information.

Identify:

- Where licence information is stored.
- Whether licence texts are currently displayed as plain text, HTML, or another format.
- How licence entries are associated with dependencies.
- Whether the current page has a detail screen or dialog.
- Whether a Markdown rendering library already exists in the project.
- Whether the application already has a reusable Markdown component.

Do not introduce a second Markdown implementation unnecessarily.

### 3.2 Markdown rendering

Implement a proper Markdown reader for open-source licence documents.

The reader should correctly handle common Markdown structures, including:

- Headings and subheadings.
- Paragraphs and line breaks.
- Bold and italic text.
- Ordered and unordered lists.
- Nested lists.
- Links.
- Blockquotes.
- Inline code and fenced code blocks.
- Tables, where supported by the selected implementation.
- Horizontal rules.

Preserve the original licence text and its legal meaning.

Do not rewrite, summarize, simplify, or omit legal clauses to make the display shorter.

If a licence is originally plain text rather than Markdown, continue to display it correctly. Do not assume every licence file is Markdown.

### 3.3 Reading experience

The reader must support:

- Normal in-app reading.
- Scrolling through long licence documents.
- A dedicated full-screen reading mode.
- Returning from full-screen mode to the previous licence page.
- Correct handling of device rotation and window-size changes.
- Appropriate text sizing and line spacing.
- Clear visual separation between headings, paragraphs, lists, code, and tables.
- Light and dark theme compatibility.
- Accessibility-friendly contrast and readable typography.

Full-screen mode should maximize the available reading area without accidentally hiding essential navigation or making it impossible to exit.

Provide an obvious way to leave full-screen mode and return to the previous screen.

The full-screen reader must not lose the current document or unexpectedly reset the reading position.

### 3.4 Legal accuracy and offline operation

- Preserve the exact licence text from its authoritative source.
- Preserve copyright notices and attribution.
- Do not replace full licence texts with shortened descriptions.
- Do not fetch licence documents from the internet every time the user opens the page.
- Keep licence reading available offline.
- Do not introduce unnecessary runtime network dependencies.

If a Markdown rendering dependency is needed, investigate whether an existing dependency can be reused before adding another one.

Any new dependency must undergo the project's normal licence audit and compatibility checks.
