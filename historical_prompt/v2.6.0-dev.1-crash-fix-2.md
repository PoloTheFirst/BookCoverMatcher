# 5. Project context and established design

BookCoverMatcher is an Android Kotlin and Jetpack Compose application.

Established architectural constraints:

- Single application module.
- Offline-first behavior.
- One `MainViewModel` owns immutable `UiState`.
- No DI framework.
- Existing Saved workbooks library remains the local persistence mechanism.
- OneDrive support uses Microsoft Graph read-only delegated access.
- Personal Microsoft accounts only.
- No upload, write-back, or remote deletion.
- Opening saved workbooks must remain local and must not require network or authentication.
- Remote refresh occurs only through explicit Rescan.
- Local workbook comments and scanning remain independent of Graph.
- MSAL public-client authentication uses PKCE and its managed encrypted token cache.

Do not introduce broad refactoring or new architecture.

The user expects precise evidence and clear distinctions between:

- Implemented vs automated-tested.
- Tests written vs tests executed.
- Instrumented tests compiled vs executed.
- APK build vs runtime verification.
- Fake-based tests vs live Graph verification.
- Static inspection vs manual verification.
