## C. The four new requirements

1. **Gallery worksheet filter** — `GalleryFilter.sheetName` (single, name-based, never wired to UI) became `GalleryFilter.sheets: SheetScope`. `GalleryView.rows` filters records by worksheet **identity** before any other filter, so it changes the dataset, not the rendering. A *Worksheets: …* bar (same component as Health/Analytics) sits under the search-bar divider and opens the shared picker (All / one / several, record counts, hidden state, **Use these worksheets**). Count line now reads `x of <eligible>`, with the scope name. `galleryOrderKey` includes `SheetScope.key`, so a scope change resets the grid and nothing else does. Stale keys reconcile; a fresh workbook starts at *All worksheets*; Gallery/Health/Analytics keep independent scopes.
2. **Imported Timeline removed** — `TimelineMode` now has exactly `PUBLICATION`/`ACQUISITION`; `CollectionTimelineBuilder.imported`, `WorkbookCommentsUi.importTimeline` and all `IMPORT` branches are gone. Import timestamps survive as metadata (`WorkbookLibraryEntry.importedAt`, `WorkbookCommentsUi.importedAt`), and the saved-workbook library is untouched. Published/Acquired mappings, filters, ordering and mode-switch scroll reset unchanged.
3. **Catalogue Table dates** — new `core/excel/comments/NumberFormats.kt`: `WorkbookStyles.read(zip)` parses `xl/styles.xml` (`numFmts`, `cellXfs/xf@numFmtId` via the ECMA-376 built-in table) and `workbookPr@date1904` once per package; `NumberFormatCodes` classifies custom codes by their own tokens (literals/escapes/brackets removed); `CellNumberFormat.display` renders `2024-01-01` / `2024-01-01 14:30`, honouring 1900/1904 and refusing serial 0 and the fictitious 1900-02-29. `SheetCells` keeps `styleIndex`/`numeric`; `CatalogueRecord.displayValues` sits beside the untouched `values`. The table and cards draw display text; filters, search, canonical catalog, timelines and export keep stored text. Prices/page counts/IDs keep their digits because only format metadata (never the value) decides.
4. **Percentage precision** — percentage-formatted numeric cells render `12.35%` (scaled once, ≤ 2 decimals, trailing zeros dropped, `-0%` suppressed to `0%`). Non-percentage cells never gain `%`; text cells (`"12.35%"`) are never rescaled; stored values are never rounded.

Bonus consistency fix found while verifying: the Timeline/Analytics/Health read serials with the 1900 epoch only. `WorkbookAnalysis.date1904` now carries the workbook’s own date system into `CatalogDates.parse`, so a 1904 workbook cannot show one year in the table and another on the timeline (new test).
