## B. Feature implementation

### B.1 Markdown reader for the licence documents

| File | Role |
|---|---|
| `core/markdown/Markdown.kt` | Public entry (`parse`, `parseInline`), the block/run models and the HTML allowlist |
| `core/markdown/MarkdownParser.kt` | Block parser: headings, paragraphs, hard breaks, lists, quotes, fenced code, tables, rules, images, HTML runs, comment stripping |
| `core/markdown/MarkdownInline.kt` | Inline parser: bold, italic, strikethrough, code spans, links, inline images, `<https://…>` autolinks, escapes |
| `ui/markdown/MarkdownView.kt` | `MarkdownDocument` composes the blocks in the app's palette; link runs become real Compose links through `AuthorProfile.linkTarget` |
| `ui/LicenseReaderDialog.kt` | The reader: document tabs, loading/failure states, full-screen toggle, back handling, hoisted scroll |

Supported constructs: headings (`#`…`######`), paragraphs with Markdown soft-wrap and two-space/backslash hard
breaks, bold/italic/strikethrough, inline and fenced code (language kept), ordered, unordered and nested lists
(levels are retained and indented), links, autolinks, image blocks and inline images as linked alt text,
blockquotes, tables (header row plus body rows; alignment markers are ignored), and horizontal rules.

Plain text is handled deliberately: the GNU GPL is not Markdown and contains `<year>` and
`<one line to give the program's name…>` placeholders. HTML is therefore recognised through an **allowlist of known
element names**, so those placeholders stay text, and a `<!-- … -->` comment is removed entirely. Embedded content
is never executed: a run of badge `<img>` tags becomes one line naming the alt texts that were not displayed.

**Full-screen behaviour:** the reader opens at dialog size; *Full screen* re-renders the same document in a window
that fills the screen (`usePlatformDefaultWidth = false`, system-bar padding) with a larger text size and an
always-visible *Exit full screen* control. The selected document (`rememberSaveable`) and the scroll position (one
`ScrollState` hoisted above the mode branch) survive the switch and rotation. Back, and the dialog's dismiss
request, leave full screen first and close the reader only on a second press.

**Offline:** documents are read from `assets/licenses/` once per selection. There is no network call anywhere in this
path, which was verified with airplane mode enabled.

**Tests:** `MarkdownTest` — **20 passed** — including `theShippedLicenseLosesNoText`, which parses the real `LICENSE`
and asserts that every line's words survive (the legal-accuracy guard), and
`theBundledReadmeParsesIntoReadableBlocks`, which parses the packaged README and asserts the template comment is
absent and the badges are reported.

**No dependency was added.** The reader is project code, so the licence surface did not grow.

file whose extension lies. It is decoded from the APK's assets at runtime with `BitmapFactory`; if decoding ever
fails the panel shows a neutral `P1` placeholder instead of an empty box, and the image carries the content
description "PoloTheFirst's GitHub profile picture". No network request is made to display it.

**Identity.** The username and nickname are separate values rendered in separate labelled fields — `PoloTheFirst`
as the GitHub username, `Nickname  Polo01` below it — and a test asserts they are distinct and exact, because
substituting one for the other is the mistake this section exists to avoid.
