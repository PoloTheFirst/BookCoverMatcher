## 4. UI and browsing

Provide authorization, loading, empty, error, retry, cancellation, Up/breadcrumb, Load more, progress, Use it now and Done states. Back closes the browser. My Drive and nested folders are in scope. Shared drives, Shared with me, shortcuts and Google Sheets conversion are excluded. Exclude trashed items; keep folders navigable. Only .xlsx/.xlsm, case-insensitively, can be selected. Check MIME metadata without excluding valid generic-binary uploads. Validate again before and after download. Empty filtered pages must not hide subsequent pages. Treat IDs and page tokens as opaque.

## 5. Import and storage
Reuse streaming safe download, OOXML validation and WorkbookLibrary import. Never buffer complete workbooks or expose partial downloads. Clean up cancelled, failed and invalid downloads. Preserve .xlsm bytes without executing macros. Handle missing files, restricted downloads, storage failure and duplicates. Add explicit Google Drive origin while preserving local/OneDrive records. Do not repoint existing duplicate entries to another provider. Avoid provider/account identity collisions; Google imports do not persist remote IDs or enable remote refresh in this initial scope.

## 6. Scope and architecture

Google Rescan parses only the local copy and never invokes OneDrive. No Google sync, background refresh, upload, write-back or remote deletion. Existing OneDrive import/update behavior must remain functional. Add only necessary dependencies; audit licences and update notices. Report accurate Google errors without exposing tokens, response bodies, identities or workbook names in diagnostics.
