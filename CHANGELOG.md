## v2.5.0-dev.3 (2026-11-05)

# Repair SauceNAO key storage and simplify IQDB results

Users can configure a SauceNAO key and replace it without deleting a working one first. IQDB results have clearer controls on the Online tab.

### Added

- Add a per-card dismiss action to IQDB-only results and a Replace action for a stored SauceNAO key.

### Changed

- Keep the IQDB paste section expanded and distinguish key-format errors from a storage failure.

### Fixed

- Save the initialization vector generated by the encryption cipher. Reset stale request state when configuring a new key and improve readability of the IQDB suggestion.

### Removed

- Remove the duplicate Listing Candidate entry flow and its obsolete tests.

### Tests

- The historical suite recorded 876 tests in 108 classes, zero failures and seven skipped. Tests covered the encryption envelope, non-repeating initialization vectors, key validation and result dismissal.

### Verified

- The recovered original APK declares 2.5.0-dev.3, code 218. Its signed bytes match the historical GitHub asset with SHA-256 df288ce7ce56f5cfbd961604fa4d14ced6472c6b27e3de4aa6ca9af40c2dc62f. The release audit verified its original signing certificate.
- The historical emulator test completed a live SauceNAO query. After key replacement it checked readiness and decryption.

### Known limitations

- The original asset attached under this release was an internal release candidate for a different version. The recovered original is the development build. The second live call after replacing the key was not repeated. IQDB remains manual.
