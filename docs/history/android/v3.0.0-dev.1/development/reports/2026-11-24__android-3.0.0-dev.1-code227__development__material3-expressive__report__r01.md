# Material 3 Expressive development build

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

Implemented the approved Material 3 Expressive refresh in local **v3.0.0-dev.1 (227)**. The Play edition opens with an empty Plugins tab. The explicit GitHub edition on `main` includes Plugin Marketplace and its five groups, ready to use offline on a fresh install. The published standard APK remains v2.7.0 (226).

## Scope and baseline

The [approved series proposal](../../../v3.0.0/development/prompts/2026-11-24__android-3.0.0__development__material3-expressive__prompt__r01.md) defines the UI and branch rollout. The owner assigned the dotted development suffix and code 227 after approving the design. On 24 November the owner requested a visible glow, a website-inspired treatment, and a Display button that can follow the phone. The upgrade baselines were published Play source `261d9da` (226) and legacy explicit `eed8f60` (224).

## Changes and decisions

- Material 3 **1.5.0** supplies the Expressive theme. Compose BOM **2026.09.00** resolves UI and Foundation **1.12.1**. Compile SDK is 37, target SDK 36 and minimum SDK 26. The project retains its existing application ID and signing configuration.
- More → Display offers Follow system (initial setting), Light and Dark. Selecting an appearance updates the running app and both system bars; a local preference retains the selection. The Atelier website’s `src/config/siteConfig.ts` and `src/styles/atelier.css` informed the Sophie colors, editorial serif heading and fine panel outlines. The app keeps the BCM book artwork and cyan/teal scanner glow. The phone’s day/night mode selects the Sophie scheme when following the system.
- The five destinations share a navigation indicator, type, tonal surfaces and action styles. Workbook rows retain source, link and account details. Primary actions, result controls and document readers accommodate large text. On a narrow display with enlarged text the navigation uses multiple rows and keeps More beside Plugins.
- The Play flavor keeps the empty plugin host, on-device PaddleOCR and selectable Chrome Lens. Provider integrations stay outside the Play package. Standalone provider builds still require descriptor import. The standalone marketplace still downloads its supported descriptors after activation.
- Main validates its bundled descriptors locally and uses the existing plugin IDs and activation paths. Existing choices and removals take precedence. Turning the marketplace off pauses its children while keeping the switches in their saved positions. Removed groups can be restored from the APK. A user action and the provider’s existing settings still control online interactions.
- Platform order is Ordinary Library Fetch (0), DLsite Fetch (1), Doujin Shop Shortcuts (2), Explicit Database Shortcuts (3) and Reverse Image Discovery (4). The framework branch contains shared UI and lifecycle contracts independently of the provider branches.
