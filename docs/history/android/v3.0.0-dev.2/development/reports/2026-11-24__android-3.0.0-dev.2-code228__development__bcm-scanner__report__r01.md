# BCM display name and Material 3 Expressive scanner

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

BCM is the launcher and Home name for **v3.0.0-dev.2 (228)**. The scanner now shares the Material 3 Expressive controls and Sophie palette used throughout the app. Both the standard Play edition and the explicit GitHub edition include the change.

## Scope and baseline

The owner named dev.2 after the local v3.0.0-dev.1 (227) checkpoint. Following the versioning convention, dev.2 uses code 228. The Play baseline was `f777cd2` and the explicit baseline was `8aaa8e6`. The public standard release is v2.7.0 (226).

## Changes and decisions

- The launcher, serif Home heading, first-run model screen and current app-facing copy use **BCM**. Android still identifies the app as `com.bookcovermatcher`. The repository, existing plugin folder, URLs and provider registrations retain their identifiers.
- The scanner uses the website’s cream/rose light palette and plum/blush dark palette. Follow system is the default; **More → Display** retains the existing overrides. Expressive shapes and a glowing capture frame carry the accent into the scanner. Theme colors surround the camera image and leave the captured pixels intact.
- The live status and Auto-scan stability meter sit below the viewfinder. **Sharp**, **Light** and **Steady** expose individual states. The capture, Auto-scan and Restart camera actions allow wrapping or reflow at larger type sizes.
- The scanner waits for CameraX to report a streaming preview before enabling capture after startup or restart. A camera that is off can still be started from Home. Original guide proportions, image analysis, matching and workbook storage are retained.
