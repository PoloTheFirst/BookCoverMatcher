# Standard GitHub release of v2.7.0

## Outcome

GitHub published v2.7.0 (226) as Latest on 24 November 2026. Its single installable asset is the owner-signed Play edition. [GitHub release](https://github.com/PoloTheFirst/BookCoverMatcher/releases/tag/v2.7.0) · [Download the APK](https://github.com/PoloTheFirst/BookCoverMatcher/releases/download/v2.7.0/bookcovermatcher-v2.7.0.apk)

## Scope and baseline

The owner selected the `google_play` branch for the standard GitHub distribution. The public tag resolves to `261d9da2a3f8f511e3a864f68a12d29d6ab8b0f5`. The publication check confirmed that `main` still pointed to `eed8f60236873822a9ac4af67671f7ec64f50c7c`.

## Changes and decisions

The owner unlocked the existing release keystore locally. The release uses the same signing certificate as the previous owner-signed Play APK. The owner selected GitHub as the distribution channel for this release.

## Verification and evidence

- Android Build Tools 36.0.0 verified the APK signature, 16 KB ZIP alignment, package ID `com.bookcovermatcher`, version name 2.7.0 and version code 226.
- A SHA-256 comparison of each of the 541 payload files matched the tested unsigned release build.
- The published asset `bookcovermatcher-v2.7.0.apk` is 337,658,048 bytes. Its SHA-256 is `6b509f5ce337a7d654464da16eebcc38496e9b18c22617384fc7cbe5471f2b4e`. GitHub reported the same size and digest as the local signed artifact.
- GitHub release ID 456422104 was public, stable and Latest. Its title equalled the tag, and the API body matched the tagged CHANGELOG.md including the final newline.
