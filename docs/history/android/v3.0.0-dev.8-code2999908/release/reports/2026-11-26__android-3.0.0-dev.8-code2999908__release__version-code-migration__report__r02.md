# Android archive validation and v2.5.0 license reader recovery

## Archive context

This report supersedes [the initial validation](2026-11-26__android-3.0.0-dev.8-code2999908__release__version-code-migration__report__r01.md) following a comparison of the original v2.5.0 APK’s DEX class definitions.

## Outcome

The final owner-signed v2.5.0 APK uses code 2050000, retains all 16,462 original DEX class names and contains both original license texts byte for byte. Its SHA-256 is `6a36312a7d589c0937a69635c94f73f41783e86d196d81099998fbfbb6905c5a`. The [archive artifact manifest](../../../../../../tools/archive-rebuild/artifacts.json) records this corrected artifact and the other 43 signed rebuilds.

## Scope and baseline

The original v2.5.0 download contained the license reader, two entry buttons and bundled notices. The historical v2.5.0 tag omitted the reader and the Gradle task that packaged its documents. The first build from that tag lacked fourteen DEX class definitions. The owner’s archive migration covers the original features as well as the version metadata.

## Changes and decisions

Recovered the three affected source files from public commit `a490ca0228331c244c6a04d1af782343110fb088`. The [rebuild guide](../../../../../reference/ARCHIVE_REBUILDS.md) links the exact source diff. The public helper applies this correction alongside the previously documented Kotlin byte-order-mark fix, checks the resulting Gradle file, and restores the notice bytes from the verified original after confirming that both texts match the tagged files under line-ending normalization.

## Verification and evidence

- Prepared and built a separate v2.5.0 source tree using the public helper and the edition’s dependency constraints. Both the independent and owner-signed APKs match the original set of 16,462 DEX class names and the exact bytes of `assets/licenses/GPL-3.0.txt` and `assets/licenses/THIRD_PARTY_NOTICES.md`.
- Compared 481 DEX, manifest, compiled resource, model, license and native entries between the independent and final owner-signed v2.5.0 APKs by SHA-256. Every member matched.
- Matched the final signed archive identities against the manifest for all 44 additional APKs. Version calculator tests cover the actual Android names of both historical tag exceptions.
- Ran the documentation consistency checker, focused regression tests, staged Git whitespace checks and repository licensing audit in both active source trees.

## Outstanding work and risks

The certificate differences and original debug builds recorded in r01 continue to apply. A DEX class-name comparison checks the class inventory. Rebuilt APK bytes, signatures, packaging and some generated toolchain artifacts can differ from the originals. No live cloud or workbook operation was exercised during this source correction.
