# The BCM open-book logo

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

BCM 3.0.0-dev.3 (229) uses an open book with a four-point glint on its right page. The owner’s final selection uses a cream light tile with pale blush and ivory pages outlined in rose, and the earlier rose tile for dark mode. Android can tint a separate silhouette for users who enable launcher-themed icons.

## Scope and baseline

The owner requested a Material 3 Expressive logo using the Polo’s Atelier Sophie palette after v3.0.0-dev.2 (228). The request covers the standard Play edition, the explicit GitHub edition and their framework/plugin builds. The published dev.2 Play tag is `98c0e11`. This release keeps `com.bookcovermatcher`, the existing signing setup, provider boundaries and storage formats.

## Changes and decisions

The editable [logo SVG](../../../../../../branding/source/bookcovermatcher-logo.svg) contains both colorways. In light mode the book uses a cream tile (`#FAF5EF`), pale blush and ivory pages, and a rose outline 1.35 units wide. Dark mode uses blush and ivory pages on deep rose (`#80435C`). The same two page curves and transparent glint form the monochrome layer. Home uses **More → Display** and crops the adaptive artwork like the launcher. The full-color launcher reads Android’s resource configuration.

The [branding guide](../../../../../../branding/README.md) documents the regenerated 120px OAuth image, 512px Play icon, 1024px master and 1024×500 feature graphic. The exporter generates the Android vectors and refreshes PNG sizes and SHA-256 checksums. Source and exports are included in the repository. Website and Console updates are separate actions.

## Verification and evidence

- Play debug and release APKs assembled on CachyOS with the Gradle wrapper. 1,271 JVM tests passed and 12 were skipped. Lint reported zero errors and 61 warnings.
- Checked the compiled resource table, application label **BCM**, package ID, development version, retention of OCR/model assets and the Play/explicit plugin boundary. Both editions’ release APKs passed native ELF and ZIP alignment checks for 16 KB pages.
- Rendered the vector layers at 4× resolution. The outermost visible artwork was 31.68 dp from the center, inside the adaptive icon’s 33 dp safe radius. Compared the rendered light vector pixel-for-pixel against the approved option A preview across the entire book. Verified the transparent glint and page crease in the monochrome layer, the four exported PNG dimensions and the manifest hashes. The 120px PNG is 2,877 bytes.
- Android 8 and 16 emulator launchers and BCM Home displayed the selected light artwork after an in-place upgrade from dev.2. On Android 16 the fixture files and first-install timestamp survived. Home followed the system and honored both manual overrides. Switching themed icons on and off changed the Pixel Launcher silhouette and restored its original colors. In dark mode Android app info and BCM Home showed the rose icon immediately. Pixel Launcher cached the light icon across a launcher restart and showed the dark icon after a package refresh. Device evidence and the direct before/after comparison are in `verification.json`, `pixel-launcher-cache.json` and `light-before-and-after.png`.
- The seven local framework, marketplace and provider builds all passed their compiled-artwork and branding checks. Across those branches 9,686 JVM tests passed, 96 were skipped and lint reported zero errors. Per-branch receipts are in the sibling `plugins/verification.json` QA file.
- Local QA artifacts are under `~/.local/share/BookCoverMatcher/qa/v3.0.0-dev.3/chosen-a/`. The full-color comparison is `bcm-logo-preview.png`, artwork measurements are in `logo-geometry.json`, and packaging checks are in `artifacts.json`.
- Tested Play debug APK SHA-256: `ac5ba3d02b1f066ee3f02a7012f050d4e10fd0b2ea60b8cb9009b6a4abc0a51a`. Unsigned release APK SHA-256: `8fcfa72cf62384bdf0f4918041bc499d0c50b65a2a676c7412e316ee5ccc07da`.

## Outstanding work and risks

Device testing used Android emulators. A phone manufacturer’s launcher can apply a different mask, tint or icon caching behavior.
