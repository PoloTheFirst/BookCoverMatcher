# BCM and BCM Plus dev.5 publication

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

Published both signed editions in the [v3.0.0-dev.5 GitHub prerelease](https://github.com/PoloTheFirst/BookCoverMatcher/releases/tag/v3.0.0-dev.5). GitHub continues to designate v2.7.0 as the latest stable release.

## Scope and baseline

BCM comes from google_play. BCM Plus comes from main. Both use Android version code 231 and the existing application ID com.bookcovermatcher.

## Changes and decisions

The release notes are the complete tagged CHANGELOG.md. The standard release tag identifies BCM and the companion v3.0.0-dev.5-plus tag identifies BCM Plus. The Plus release was built in a clean checkout using the Gradle dependency versions committed on main.
