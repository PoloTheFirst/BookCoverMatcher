## Changes and decisions

- Minimal account identity reads use existing scopes: Google Drive about.user permissionId/emailAddress/displayName and Graph /me id/mail/userPrincipalName/displayName. No new dependency or OAuth permission; tokens remain memory-only. SourceAccount redacts its string form.
- Additive optional source fields retain provider account key/label or a selected-document URI/location/read-grant flag. Legacy entries keep their data and unknown source identity. Library transactions are synchronized. Normal duplicates cannot steal local, cross-provider or different-account provenance.
- Source checks distinguish sign-out, account mismatch, revoked access, 403, generic 404/missing, timeout/offline and affirmative trash/deleted markers. Metadata-only opening checks do not block local file viewing. Paths remain last known where the provider cannot supply a new one. Session/source generation and binding checks reject stale results and updates.
- Explicit cloud re-linking downloads and validates a selected unchanged copy, compares its hash, and changes only provenance. Legacy recorded file IDs can also be bound after explicit original-account confirmation and an access check. Local re-linking verifies identical content, and unused document grants are released on replacement/removal. No original is modified or deleted.
- MainViewModel tracks the viewed entry ID independently of the scanning source. Use it now validates/stages the imported copy, opens it and dismisses both cloud panels. Rescan now targets the viewed workbook. Missing/corrupt results retain a failure/retry path. Home's Saved selector remains a selection-only operation.
- Shared source details provide complete account/path text and actions in a scrollable dialog. Import buttons retain provider names plus account/session state. Rescan/Back moved below the viewer title with flexible widths and 48dp targets after large-font screenshots exposed clipping.
- Canonical Privacy Policy revision **2026-11-14.1**, user guide, AppAuth guide, architecture and current changelog updated. A private policy synchronization handoff is prepared for the website agent; terms are unchanged.
