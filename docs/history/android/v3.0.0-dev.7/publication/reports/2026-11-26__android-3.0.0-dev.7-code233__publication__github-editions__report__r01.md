# BCM and BCM Plus dev.7 publication

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

Published both signed editions of the light/dark launcher icon fix. Both carry Android version code 233 and the existing package ID `com.bookcovermatcher`. [GitHub prerelease](https://github.com/PoloTheFirst/BookCoverMatcher/releases/tag/v3.0.0-dev.7)

## Scope and baseline

The standard source tag `v3.0.0-dev.7` points to the release commit on `google_play`. The companion tag `v3.0.0-dev.7-plus` identifies the BCM Plus release commit on `main`. GitHub’s latest stable release remains v2.7.0.

## Changes and decisions

Built BCM Plus in an isolated checkout with the Gradle version recorded on its release commit. Both APKs contain the day and night launcher resources, and each preserves its edition-specific plugins and dev.6 offline model and native library payloads.
