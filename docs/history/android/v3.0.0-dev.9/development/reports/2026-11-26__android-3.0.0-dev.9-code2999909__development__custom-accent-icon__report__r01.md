# Custom accent launcher icon

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

BCM dev.9 uses the saved custom hue for its full-color launcher icon and the book on Home. Its owner-signed local APK is `BCM-v3.0.0-dev.9.apk`, code `2999909`. This fresh release uses a single code for both editions.

## Scope and baseline

The local google_play worktree started at `df1e1fc7936b72f77da83a9ea8acf5802bb43e6f`. Dev.8 already stored an integer hue for the in-app theme. The launcher and Home used fixed Sophie artwork. This change reuses the existing display preference, package identity, workbook storage and release signing configuration.

## Changes and decisions

- Gradle generates day and night adaptive icons and manifest aliases from the original SVG, the monochrome book silhouette and 360 AndroidX HCT swatches. Android loads launcher artwork from the APK. The build adds one pair for each integer hue and treats 360° as 0°.
- The application reconciles the launcher entry with the saved palette on startup and when Display changes. Android 13 and newer switch aliases together. Earlier versions enable the new entry first. The underlying MainActivity stays launchable.
- Home renders the same adaptive layers using BCM’s appearance setting. The launcher uses the phone’s night mode. A supporting launcher can apply the phone’s themed-icon tint to the monochrome layer.
- The update uses the existing on-device hue and adds no network transfer, account operation or permission. The root policies carry forward the edition disclosures to dev.9 under revision 2026-11-26.3.
- The version calculator and the fresh-release guidelines establish a single version code and regular edition filenames. The historical rebuild index continues to describe its 35 archived releases.

## Verification and evidence

- Ran the edition’s Gradle debug build, instrumented-test build, release build, JVM suite and debug lint. BCM passed 1,271 JVM tests with 12 skipped. BCM Plus passed 1,444 with 16 skipped. Android lint completed with zero errors for both editions. The Python tooling suite passed six tests per branch.
- Debug upgrades on isolated emulators preserved an existing custom hue and a synthetic preference marker. BCM on Android 16 resumed hue 181. BCM Plus on Android 8 resumed hue 52. Both resolved the same hue after a cold launch. The tests exercised the real Display controls and checked rendered light and dark resource colors.
- Pixel Launcher showed the selected accent in light and dark mode on Android 16 (BCM, 181°) and Android 8 (BCM Plus, 52°). The book on Home matched the dark accent in both editions.
- The packaged release manifest reports `com.bookcovermatcher`, name `3.0.0-dev.9` and code `2999909`. The APK passed `apksigner verify` with the dev.8 certificate and `zipalign -c -P 16 4`. Both policy assets match the root Markdown files byte for byte. SHA-256 for this edition is `135be5222e9e57f466b9b35a5c102d28ad14fc9e1f2e5a4b03233d39793e5df0`.
- Signed emulator updates passed from dev.8 code 2999908 for BCM on API 36 and code 234 for BCM Plus on API 26. Each retained its first-install timestamp and opened through the default launcher icon.
