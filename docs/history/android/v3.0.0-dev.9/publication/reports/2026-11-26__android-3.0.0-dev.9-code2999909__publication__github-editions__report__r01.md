# GitHub publication of BCM and BCM Plus dev.9

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

Published [v3.0.0-dev.9](https://github.com/PoloTheFirst/BookCoverMatcher/releases/tag/v3.0.0-dev.9) as a GitHub prerelease with one signed APK per edition. Both use `com.bookcovermatcher` and Android version code `2999909`.

The owner authorized a two-edition GitHub prerelease after the website policy source was pushed.

## Changes and decisions
