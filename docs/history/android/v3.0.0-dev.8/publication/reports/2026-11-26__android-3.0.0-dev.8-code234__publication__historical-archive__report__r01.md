# Historical GitHub release archive repair

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

All 35 public GitHub releases have APK downloads. Each release body matches the matching tagged root CHANGELOG.md byte for byte. Eight v3 development releases use one body for both source tags and both editions. The current v3.0.0-dev.8 APKs retain version code 234.

## Scope and baseline

The 26 November 2026 audit covered 35 release entries and 43 source tags, including the eight BCM Plus companion tags. It compared Android manifest identity, release text and source metadata. The two early public tag aliases, v1.1.0 and v2.0.0-dev.1, both retain the Android version name 1.1.0-dev.1 and code 2 in their original downloads.

## Changes and decisions

Repaired 31 tag references and synchronized 30 public release bodies. Seven framework or plugin branches received notes describing their actual source checkpoints. The obsolete public dev branch was retired. No new Android version was allocated.

## Outstanding work and risks

The stable v2.4.0 rebuild assembled successfully with 17 historical JVM test failures and seven skips. The three rebuilt APKs have a different signing certificate from some earlier installations. Seven native libraries in each of the four archive APKs fail the current 16 KiB ELF check. Consult the individual release notes before installing an older build.
