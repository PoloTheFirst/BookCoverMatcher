# DLsite selection in Online

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

On main, deselecting DLsite in Online skips its searches and leaves its row available for reselection. Plugins controls whether the row appears.

## Scope and baseline

This change targets the explicit edition, 3.0.0-dev.4 (230), following dev.3 (229).

## Changes and decisions

OnlineSearchController previously disabled the whole plugin when its group had one entry. Individual catalogue selections now use separate preferences. The existing preferences used to initialize plugin activation remain available on upgrades. Users whose DLsite plugin was disabled in a previous build can enable it once in Plugins.

## Verification and evidence

On CachyOS, Gradle assembled the GitHub debug app and instrumentation APKs. The GitHub debug JVM suite passed 1,444 tests and skipped 16. All five DlsitePluginDeviceTest cases passed on an isolated API 36 emulator. The regression recreated the controller, confirmed the row remained deselected, checked zero fixture calls while disabled and one after reselection, and verified that disabling the plugin hid the row.

## Outstanding work and risks

The test uses a local provider fixture. This development build was tested locally.

## Next action and references

See the Online section in the user guide. Documentation indexes were refreshed and validated.
