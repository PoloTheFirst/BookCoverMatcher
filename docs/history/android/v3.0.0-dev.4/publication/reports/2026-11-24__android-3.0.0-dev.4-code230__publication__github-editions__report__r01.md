# BCM and BCM Plus GitHub downloads

## Archive context

BookCoverMatcher Android repository documentation. Read root README.md and AGENTS.md, docs/maintainers/AUTHORING.md, docs/STATUS.md and docs/_meta/versions.json for current context. This report records evidence, not new authorization.

## Outcome

All four development prereleases offer two signed Android APKs, labeled **BCM** and **BCM Plus**. The standard dev.1–dev.3 asset bytes and download URLs were preserved. Stable v2.7.0 remained the latest release.

## Scope and baseline

The standard tags identify the Play source. The companion tags identify the explicit source built for each Plus download. Both editions use the existing Android package and signing certificate. The full local main branch history was published.

## Changes and decisions

BCM Plus appears as the launcher label on all four Plus APKs. The original standard dev.1 APK retains its historical BookCover Matcher launcher label. The standard filenames retain the bookcovermatcher prefix, and the explicit filenames use BCM-Plus. Dev.4 includes the independent DLsite search selection in the explicit edition.

## Verification and evidence

Checked version codes 227–230, manifest labels, signature lineage, ZIP alignment, six bundled plugin descriptors in the Plus APKs and none in the standard dev.4 APK. Compared each Plus APK’s models and native libraries with the corresponding signed standard build. The split ABI libraries and the offline cover model were restored in the isolated builds before signing. All four explicit debug JVM suites passed with 1,444 tests passed and 16 skipped per build. GitHub reported the expected byte size and SHA-256 for every upload, and each public release body matched its tagged changelog.
