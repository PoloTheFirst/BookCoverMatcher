# Maintainer guidance

Read [workflow](WORKFLOW.md) for task intake and execution, [authoring](AUTHORING.md) for autonomous filing and revision rules, [versioning](VERSIONING.md) for Android/release identity, [templates](TEMPLATES.md) for record formats, and [changelog guidelines](CHANGELOG_GUIDELINES.md) for publication text.

The current owner request controls scope. Routine document naming and organization no longer require the owner to choose every filename. A prompt-only request still stops at a reviewable prompt; an implementation request does not need a redundant prompt approval cycle.

These are maintained sources, not generated pages. The former guidelines were backed up by the migration. The old misspelling CHANGELOG_GUILDELINES.md is recorded in the migration map; use the correctly spelled current path.
